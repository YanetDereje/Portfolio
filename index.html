Project Turtle: Power Monitoring System

Project Turtle features a breadboard circuit consisting an STC-013 sensor, its conditional circuit, and an ads1115 (ADC), all connected to a raspberry pi and a laptop. Through this, we were able to track the amount of power flows through an applicant and build a dashboard for users to witness real-time current.
