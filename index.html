Project Turtle: Power Monitoring System

Project Turtle features a breadboard circuit consisting of an STC-013 sensor, its conditional circuit, and an ADS1115 (ADC), all connected to a Raspberry Pi and a laptop. Through this, we were able to track the amount of power that flows through an appliance and build a dashboard for users to witness real-time current.
